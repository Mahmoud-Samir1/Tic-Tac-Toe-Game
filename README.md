🎮 Tic-Tac-Toe (XO) Game

A simple desktop Tic-Tac-Toe game developed using Windows Forms (WinForms) as part of my programming learning roadmap with Eng. Mohamed Abu Hadhoud, specifically Course 14.

The project focuses on implementing game logic, handling user interactions, and improving code organization through reusable functions.

📌 About the Project

Tic-Tac-Toe is a two-player game played on a 3×3 grid. Players take turns placing their marks ("X" or "O") in empty cells.

The goal is to get three matching marks in a row, column, or diagonal. The game ends when a player wins or all cells are filled, resulting in a draw.

✨ Features

- Two-Player Gameplay: Two players take turns playing on the same application.
- Win Detection: Checks rows, columns, and diagonals to determine the winner.
- Draw Detection: Identifies when all cells are filled without a winner.
- Game Status: Displays the current player's turn and the game result.
- Restart Game: Allows players to start a new game at any time.

🧠 What I Learned

Although this project is relatively simple, it helped me improve my problem-solving and coding skills.

- Divide and Conquer: Breaking a larger problem into smaller, manageable tasks.
- Code Reusability: Using shared functions instead of duplicating similar code across multiple event handlers.
- Code Organization: Simplifying the implementation by reducing nine separate functions to two reusable functions for handling the game cells.
- Game Logic: Implementing win and draw conditions and managing player turns.
- Event Handling: Responding to user interactions in a Windows Forms application.

One of the most important lessons was that writing code is not just about making a program work; it is also about making the code simpler, more organized, and easier to maintain.
